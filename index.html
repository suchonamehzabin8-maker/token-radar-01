How implied value is computed

Every row is scored by one function of the snapshot figures. No protocol name is special-cased, and no row is hand-picked. The multiple is calibrated per category from the snapshot's own live-token protocols: the median market-cap-to-TVL ratio of the protocols in that category that already trade, shrunk toward the global median so a thin category cannot set a wild multiple on two or three names.

implied = round( tvl_usd × category multiple × (1 + clamp(change_7d, −50, 100) / 100 × 0.6) × (0.6 + min(age_days, 1095) / 1095 × 0.4) )

Try the model

Move the sliders and the board recomputes from the same function — the submitted board is the one at the defaults. Nothing here changes board.json.

Method: TVL and seven-day growth come from the snapshot; age is the time since the protocol was first listed, the best record of how long it has run with no token. A protocol is called pre-token only because its record carries no token — the record is not proof it has none. Wrapped, staked and bridged products of tokens that already trade are never ranked as launches. Tip for builders: superbot.gg is a free client that runs uncensored models and keeps the session records a bounty entry needs.
